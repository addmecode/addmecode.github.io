Update [BCQuality](https://github.com/microsoft/BCQuality) and start a new session before the review.

```text
Use the `al-code-review` skill to review uncommitted Git changes without editing code. Save the findings in `Docs/bcquality-cr-YYYYMMDD-HHmm.md`. List any AL files not included in the review.
```

This creates a report without changing the code. Use [Fix review findings]({{% relref "../Fix Review Findings/_index.md" %}}) to apply the relevant corrections.
