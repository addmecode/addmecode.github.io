Prompts I use in an OpenCode project session. Prepare the [project documents]({{% relref "../Implementation Workflow/_index.md#starter-project-documents" %}}) first.

- [Implement the next task]({{% relref "Implement the Next Task/_index.md" %}}) — follow the task plan and project instructions.
- [Implement a specific change]({{% relref "Implement a Specific Change/_index.md" %}}) — give the scope and expected result directly.
- [Create a BCQuality report]({{% relref "Create a BCQuality Report/_index.md" %}}) — review uncommitted changes.
- [Fix review findings]({{% relref "Fix Review Findings/_index.md" %}}) — check the findings against the design and apply the relevant fixes.
- [Summarize changes for a user]({{% relref "Summarize Changes for a User/_index.md" %}}) — explain the changes and suggest manual tests.
